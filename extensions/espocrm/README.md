# Personalizaciones de EspoCRM

Esta carpeta conserva en Git las personalizaciones creadas desde el
administrador de EspoCRM: entidades, campos, relaciones, traducciones y
layouts.

Para actualizar la copia después de cambiar EspoCRM:

```bash
make espocrm-export
```

La base de datos y los secretos no se guardan aquí. Se respaldan por separado.
